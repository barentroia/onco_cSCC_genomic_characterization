Raw exome sequencing data and RNA sequencing data were made available through the European Genome Archive (Accession number EGAS50000001852). Clinical data according to the Human Tumor Atlas Network (HTAN) phase 2 data model is available upon request at the Netherlands Cancer Registry (gegevensaanvraag@iknl.nl) upon the following description: “HTAN dataset from data request numbers: K19.054 (D-SQUAME discovery cohort) and K23.132 (D-SQUAME validation cohort)”.
